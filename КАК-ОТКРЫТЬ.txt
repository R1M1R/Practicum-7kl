НЕОН-7 — как раздать урок ученикам
==================================

Это обычный статический сайт: папка с файлами, без сборки и без сервера в коде.
Ученики открывают ОДНУ ссылку (или QR на эту ссылку) в браузере телефона.

Важно
-----
1. Не раздавайте файл index.html через мессенджер «как вложение».
   С телефона протокол file:// не ставит приложение на экран «Домой»
   и может не сохранить псевдоним.
2. Нужен адрес https://... — так включаются офлайн-режим и «Добавить на экран Домой».
3. Ответы к делам и домашнему заданию в эту папку специально не положены,
   чтобы их нельзя было открыть по прямой ссылке.


Самый простой способ (рекомендуется): Netlify Drop
--------------------------------------------------
1. На компьютере откройте https://app.netlify.com/drop
2. Перетащите ВСЮ папку урока (index.html, app.js, styles.css, sw.js,
   manifest, иконки — всё вместе).
3. Через полминуты сайт выдаст адрес вида https://случайное-имя.netlify.app
4. Этот адрес можно переименовать в настройках сайта.
5. Сделайте QR-код на этот адрес (любой генератор QR, например в браузере).
6. Выведите QR на экран. Дети сканируют камерой телефона.

Пока телефон один раз открыл сайт при живом интернете, повторное открытие
работает даже если сеть в классе просела: файлы остаются в памяти браузера.


Запасной способ: GitHub Pages
-----------------------------
1. Создайте публичный репозиторий.
2. Загрузите все файлы в корень репозитория (не в подпапку, если не хотите
   длинный адрес; если файлы лежат в подпапке, ссылка должна вести прямо
   на неё — относительные пути это позволяют).
3. Settings → Pages → Branch main → / (root) → Save.
4. Откроется адрес https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПО/
5. QR ведите на этот адрес, не на github.com.


Как проверить до урока
----------------------
- Телефон учителя: открыть ссылку, ввести псевдоним, пройти один шлюз,
  пощёлкать дело, нажать «Скопировать задание».
- Второй телефон: тот же адрес, другой псевдоним. Прогрессы не смешиваются,
  они хранятся в самом телефоне (localStorage).
- На проектор для разбора: добавьте к ссылке ?demo=1
  Пример: https://ваш-сайт.netlify.app/?demo=1
  Колонка станет шире. На телефонах учеников этот параметр не нужен.


Экран «Домой»
-------------
Android (Chrome): меню браузера → «Установить приложение» или
«Добавить на главный экран».
iPhone (Safari): «Поделиться» → «На экран Домой».
Обычная вкладка тоже подходит для урока. Установка не обязательна.


Если правите урок после того, как дети уже заходили
---------------------------------------------------
В файле sw.js смените строку const CACHE = 'neon7-v1' на neon7-v2
(и дальше по счётчику) и залейте файлы заново.
Иначе отдельный телефон может ещё несколько минут держать старую копию.


Чего не делать
--------------
- Не публикуйте рядом файл с ответами: адрес можно угадать.
- Не ведите QR на папку в облаке, если она открывается как список файлов,
  а не как само приложение.
